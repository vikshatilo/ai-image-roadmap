# Дорожня карта: Генерація та редагування зображень за допомогою ШІ

## Як відкрити
1. Розпакуйте архів.
2. Відкрийте `index.html` у браузері (Chrome, Edge або Firefox).
3. Для публікації на GitHub Pages завантажте `index.html` у корінь репозиторію або папки сайту.

## Можливості
- адаптивний сайт для комп’ютера, планшета й телефона;
- інтерактивний чекліст 8 етапів із локальним збереженням прогресу в браузері;
- конструктор промпту з копіюванням;
- контроль якості, безпеки й етичного використання;
- форма короткого звіту з експортом у TXT;
- друк дорожньої карти.

Сайт не потребує встановлення бібліотек або сервера.
